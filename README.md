# 📑 Atherian Tasks

> Uma aplicação web prática e intuitiva de gerenciamento de tarefas (To-Do List), projetada para auxiliar na organização de rotinas, planejamento de atividades e acompanhamento de metas diárias.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco no fortalecimento do aprendizado em **JavaScript moderno (ES6+)**, manipulação dinâmica do DOM, manipulação de arrays de objetos e persistência de dados no navegador (`localStorage`). A aplicação permite ao usuário criar, organizar, concluir e excluir tarefas de forma fluida e responsiva.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica e criação dos formulários de inserção.
* **CSS3:** Estilização visual moderna, layouts dinâmicos e design responsivo.
* **JavaScript (ES6+):** Lógica de gerenciamento de estado, manipulação de eventos e armazenamento local (`localStorage`).
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Criação de Tarefas:** Adição simples e rápida de novas tarefas à lista.
* **Status de Conclusão:** Marcação de tarefas como concluídas ou pendentes de forma interativa.
* **Remoção de Itens:** Exclusão individual de tarefas concluídas ou desnecessárias.
* **Persistência de Dados:** Salvamento no navegador (`localStorage`) para evitar perda de dados ao recarregar a página.
* **Interface Responsiva:** Design otimizado para navegação contínua em computadores e dispositivos móveis.
